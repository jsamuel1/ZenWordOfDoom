### Task 4: Scene-coupled anchor word in `WheelPicker`

**Files:** modify `Sources/LevelGen/WheelPicker.swift`; test in `SceneLexiconTests` or a new `WheelPickerSceneTests`.

Add a scene-aware overload that prefers a **scene-related** word of the band's length, deterministically, falling back to the existing theme-anchor path when the scene has no word of that length.

- [ ] **Step 1 — failing test:** for a scene whose lexicon contains a length-N word, the derived wheel's letters are a permutation of that word.

```swift
func testSceneAnchorUsesSceneWordWhenAvailable() {
    // still-pond has length-6 words; medium band ⇒ N=6
    let wheel = WheelPicker.wheel(sceneID: "still-pond", theme: .zen, band: .medium, index: 0)
    let letters = String(wheel.tiles.map(\.letter)).sorted()
    let sceneWords6 = SceneLexicon.shared.words(for: "still-pond").filter { $0.count == 6 }
    XCTAssertTrue(sceneWords6.contains { $0.sorted() == letters })
}
```

- [ ] **Step 2 — run, expect fail** (no such overload).
- [ ] **Step 3 — implement.**

```swift
public static func wheel(sceneID: String, theme: Theme, band: DifficultyBand, index: Int) -> Wheel {
    let n = wheelLength(for: band)
    let sceneCandidates = SceneLexicon.shared.words(for: sceneID).filter { $0.count == n }.sorted()
    guard !sceneCandidates.isEmpty else { return wheel(theme: theme, band: band, index: index) }
    var rng = SeededRandom(seed: seed(theme: theme, band: band, index: index))
    return Wheel(letters: sceneCandidates[Int(rng.next() % UInt64(sceneCandidates.count))])
}
```
